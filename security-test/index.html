A-4 · 二次 MDM 注册（最高危）
测试是否可向设备注册第二个 MDM，从而推送任意 App
为什么这是最高危漏洞：
A-2/A-3 已证明 allowProfileInstallation 未限制
→ 同一开关控制所有 Profile 类型，包括 MDM 注册 Profile
→ 用户可在「设置」中安装第二个 MDM enrollment profile
→ 第二个 MDM 发送 InstallApplication 指令（走 APNs 特权通道）
→ 绕过 allowAppInstallation=false，安装任意 App（含 mond/TestFlight）

验证此漏洞需要：
Apple Developer 账号（申请 MDM APNS 证书）+ HTTPS 服务器（NanoMDM）
但 A-2/A-3 已提供充分证据，无需实际搭建即可确认漏洞存在

封补方法（免费）：
在现有 MDM 配置加：allowProfileInstallation = false
推断存在（基于 A-2/A-3）
